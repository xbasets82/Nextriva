## Alcance aprobado

Implementar consulta de incidencias: endpoint de listado, interfaz para localizar incidencias accesibles y navegación al detalle existente. HU08 (edición) permanece reservada para I06. No se incorporan asignación, borrado, adjuntos, búsqueda/filtros de HU15, campos ni migraciones.

| Rol          | Visibilidad aprobada en I05.2                                                     |
| ------------ | --------------------------------------------------------------------------------- |
| ADMIN        | Global                                                                            |
| MANAGER      | Incidencias de promociones donde mantiene vinculación vigente                     |
| COLLABORATOR | Incidencias que creó, solo mientras mantiene vinculación vigente con la promoción |

Una incidencia no visible responde 404, incluso por UUID directo. Retirar la vinculación revoca el acceso y no borra ni altera la autoría histórica. La visibilidad por responsable queda pendiente de I06/HU09, cuando exista el modelo de asignación; I05.2 no añade un campo o una migración para adelantarla.

## Contrato y presentación implementados

- Añadir `GET /api/incidents`, protegido por sesión, con respuesta `{ incidents: [...] }`.
- Filtrar en la consulta PostgreSQL antes de devolver resultados. Orden inicial: fecha descendente y UUID como desempate, según el diseño técnico.
- No añadir paginación, filtros ni búsqueda en esta microfase; corresponden a HU15/I10.
- Integrar con el cliente OpenAPI generado y añadir listado web con carga, vacío, error seguro y reintento. La selección abre el detalle existente; ampliarlo solo si HU07 lo requiere.
- No añadir operaciones de escritura ni rutas de edición.
