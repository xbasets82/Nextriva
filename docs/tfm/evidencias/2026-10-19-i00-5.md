## Alcance y cambios

Se fijaron ESLint 10.13.0, `typescript-eslint` 8.71.2, SonarJS 4.2.2,
Prettier 3.9.10, Husky 9.1.7, lint-staged 17.6.0 y Pino 10.4.0. SonarJS y las
herramientas de calidad son locales; no se configuró un servicio SaaS. La licencia
directa de SonarJS es LGPL-3.0-only; las demás dependencias directas nuevas se
identificaron como MIT.

Se añadieron scripts de lint, formato, archivos staged, tests HTTP y preparación
de Husky. El hook de pre-commit es una ayuda local; no reemplaza las validaciones
directas ni la futura CI de I00.6. Los globs excluyen salidas generadas y
`pnpm-lock.yaml`, que administra pnpm. No se cambió `.gitignore`.

La API registra un `requestId` validado (máximo 64 caracteres, alfabeto seguro)
o genera un UUID. Pino registra método, ruta parametrizada, estado y duración.
El middleware permite explícitamente esos metadatos y no registra cabeceras,
URL completa ni cuerpo. Pino elimina además las rutas sensibles configuradas
(cookies, autorización, contraseñas, tokens, URL/credenciales de base de datos y
cuerpos). Esta redacción por rutas no se considera un saneador recursivo universal.
No se añadieron cabeceras de respuesta ni cambió el contrato HTTP.

la captura de stdout se creó después de inicializar Pino y el test inicialmente
construía Nest directamente en lugar de usar la factoría de la aplicación. Se
ajustó el arnés/factoría y se observó después el RED funcional descrito arriba.
También se reemplazó una importación de Express sin tipos disponibles por tipos
HTTP de Node. No se ocultaron esos errores como fallos esperados.

Límite de evidencia TDD: el RED previo a implementar request logging comprobó la
ausencia de registro con un `requestId` esperado. La prueba unitaria aislada del
fallback UUID para ID ausente o inválido se añadió después de implementar la
resolución y pasó; no se observó un RED separado para ese caso. No se presenta
como RED independiente.

Se capturó una petición real `GET /api/health` con identificador sintético. El
registro saneado observado fue:

  "time": 1792423582779,

  "method": "GET",

Se omitieron del ejemplo el PID y el hostname local. Los marcadores sintéticos
de cookie, autorización, token y query no aparecieron en el registro.
