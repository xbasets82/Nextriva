# Formulario de edición de promociones

Fecha: 25/10/2026. Issue [#103](https://github.com/xbasets82/Nextriva/issues/103), aprobada. Rama `codex/issue-103-promotion-edit-form`, creada desde `main` actualizado en `7438c9690e1b56f3c9e294076b304bf9e0e6c931`, que integra la PR #102 / Issue #101.

## Alcance y decisiones

Al editar una promoción, el formulario sustituye visualmente al detalle: se muestran únicamente los datos editables de la promoción y sus fases; no se renderizan las secciones de incidencias ni participantes. Guardar y Cancelar comparten un grupo accesible, alineado a la derecha y con estilos coherentes con el formulario de usuarios. Cancelar aparece antes de Guardar para dejar la acción primaria en el extremo derecho. Se conservan las validaciones, la petición de guardado, los errores y la confirmación de descarte.

No cambian API, permisos, autenticación, persistencia, OpenAPI, esquema ni migraciones. Las pruebas E2E utilizaron API real y PostgreSQL temporal aislado. No se utilizó `nextriva_dev`.
